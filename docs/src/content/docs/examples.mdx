Every file on this page is rendered directly from the
[`examples/`](https://github.com/rapidity-rs/lets/tree/main/examples)
directory in the repository, and each one is parsed, validated, and dry-run
by the test suite on every commit — what you see here is guaranteed to work
with the current release. Clone the repo, `cd` into any example, and run the
commands listed in its header comment.
